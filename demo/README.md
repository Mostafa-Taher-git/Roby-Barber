# العرض التجريبي (Demo)

هذه هي **النسخة التجريبية الأولى** من روبي باربر — صفحة ويب واحدة تعمل بدون أي تثبيت،
وكانت أساس تصميم التطبيق الحقيقي.

## التشغيل

* اضغط دبل كليك على `تشغيل_الصالون.bat` — أو افتح `index.html` بالمتصفح مباشرة.

## مهم

* البيانات في هذه النسخة تُحفظ **داخل المتصفح فقط** (localStorage) — لا قاعدة بيانات،
  ولا نسخ احتياطي، ولا قفل ترخيص.
* لا تستخدم هذه النسخة في العمل الفعلي — نسخة العمل الرسمية هي تطبيق Windows
  (مجلد `apps-desktop`، يُسلَّم كملف Setup.exe).

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | صفحة العرض التجريبي الكاملة |
| `app.js` | منطق العرض (جافاسكربت قديم) |
| `styles.css` | التصميم الذهبي/الداكن الأولي |
